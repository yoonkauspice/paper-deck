O1 문체 지표

그림 3
시뮬레이션 대화는 더 길고 어려운 어휘를 많이 씁니다.
문장 길이는 중앙값이 같고 실제 대화의 흩어짐이 더 큽니다.
문체 지표 4개의 비교방향과 유의 여부만 표시, 수치는 원문 그림 3
지표시뮬레이션 대 실제중앙값 차이해석
단어 수시뮬레이션이 많음유의(p<0.001)더 장황한 텍스트
글자 수시뮬레이션이 많음유의(p<0.001)더 장황한 텍스트
평균 문장 길이중앙값 일치유의하지 않음실제 대화의 흩어짐이 큼
SAT 어휘 비율시뮬레이션이 높음유의(p<0.001)더 복잡한 언어

Key Findings

  1. 더 장황함단어와 글자가 모두 많음
  2. 더 복잡한 어휘SAT 어휘 비율이 높음
  3. 문장 길이는 비슷길이 차이는 문장 수에서 생김
1검정:중앙값 독립표본 검정, α=0.005, n=818
출처: Jeon et al. (2025) §3.3.1, 그림 3, p.12

O1 GPT-4o 기반 지표

그림 4
GPT-4o가 평가했을 때 시뮬레이션 대화가 문법, 관련성, 적절성에서 더 높게 나옵니다.
실제 트위터 대화는 주제에서 벗어나거나 덜 격식 있는 표현이 많았습니다.
GPT-4o 기반 지표 4개의 비교네 지표의 중앙값 차이가 모두 유의
지표시뮬레이션 대 실제중앙값 차이저자의 설명
내용 품질시뮬레이션이 높음유의(p<0.001)내용, 문법, 관련성 모두에서 앞섬
문법의 정확성시뮬레이션이 높음유의(p<0.001)문법을 더 효율적으로 사용
상호작용의 관련성시뮬레이션이 높음유의(p<0.001)루트 댓글과 더 직접 연결
언어의 적절성시뮬레이션이 높음유의(p<0.001)GPT-4o의 유해 표현 방지 지침 때문으로 설명

Key Findings

  1. 더 매끄러운 대화실제 대화보다 일관성과 관련성이 높음
  2. 더 점잖은 어조모델의 안전 지침이 어조를 통제함
  3. 평가 방식Lin et al.의 프롬프트 평가를 따름
1평가 모델:GPT-4o 2024-08-06 버전
출처: Jeon et al. (2025) §3.3.2, 그림 4, p.12–13

O1 GPTZero 지표

그림 5
탐지기 지표에서는 perplexity와 simplicity만 유의한 차이가 났습니다.
사람 대화가 예측하기 어렵고 시뮬레이션 대화가 따라가기 쉽습니다.
GPTZero 지표 4개의 비교유의한 것은 perplexity와 simplicity
지표시뮬레이션 대 실제중앙값 차이해석
가독성큰 차이 없음유의하지 않음실제 대화의 변동이 약간 큼
burstiness큰 차이 없음유의하지 않음단어 반복 정도는 비슷함
simplicity시뮬레이션이 높음유의(p<0.001)시뮬레이션이 더 쉽게 읽힘
perplexity실제 대화가 높음유의(p<0.001)실제 대화가 덜 예측 가능

Key Findings

  1. 탐지 단서예측 가능성이 합성 텍스트의 흔적으로 남음
  2. 토큰 선택 방식의 차이저자는 GPT-4o와 사람의 샘플링 방식이 다르다고 해석함
  3. 정리알고리즘 지표가 더 뚜렷하게 차이를 드러냄
출처: Jeon et al. (2025) §3.3.3, 그림 5, p.13–14, §4, p.19

O2 진실과 거짓의 차이

표 3
진실 뉴스와 거짓 뉴스의 대화는 15개 지표 중 5개에서 유의하게 달랐습니다.
진실은 평균 긍정, 거짓은 평균 부정이며 거짓에서 감성 반전이 더 잦았습니다.
유의한 5개 지표검정 15개, 각 틀 n=40, 수치는 원문 표 3(확인 필요)
유의한 지표원문이 서술한 방향뜻
BIASED WORDS차이가 유의함(방향은 표 3)편향어 사용량이 다름
SO(B) 감성 방향 평균진실 + / 거짓 −진실은 긍정, 거짓은 부정으로 기움
B(RoBERTa)진실 + / 거짓 −모델 기반 평균도 같은 방향
SO(D) 감성 분산차이가 유의함(방향은 표 3)의견 분산 정도가 다름
HAS DRIFT거짓에서 더 많음긍정과 부정의 우세가 뒤바뀜

Key Findings

  1. 거짓이 더 부정적NELA와 RoBERTa 두 방법에서 같은 방향
  2. 감성 반전거짓 틀에서 더 자주 나타남
  3. 나머지 10개다른 어휘 지표와 구조 지표는 유의하지 않음
1나머지 10개:유의한 5개를 뺀 값으로, 유의 여부는 원문 서술 기준
출처: Jeon et al. (2025) §3.4, 표 3, p.16–17, §4, p.17–18
