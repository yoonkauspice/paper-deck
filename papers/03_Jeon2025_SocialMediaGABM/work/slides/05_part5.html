저자의 한계 서술

논문 §4.1, §5
저자들은 순차 시뮬레이션, 단순한 에이전트, 비교 자료의 한계를 직접 적었습니다.
파란 선은 결과 해석에 직접 관련된 항목입니다.
저자 서술 한계 6가지파란 선: 결과 해석에 직접 관련
순차 시뮬레이션

한 스텝에 한 에이전트만 움직여 조직적 캠페인의 동기화나 고빈도 상호작용을 담지 못함

단순한 프로필

입장과 정보 개방성만 모형화하고 이념, 종교, 성별 프로필이 없음

제한된 맥락

원글, 직전 글, 상호작용 변수만 쓰고 장기 기억이 없음

비교 자료의 한계

Twitter16 글이 모두 사람이 쓴 것인지 보장할 수 없음

지표의 한계

지표마다 한계가 있어 여러 지표의 수렴 증거로 판단함

LLM의 한계

더 예측 가능한 글을 만들고 세션마다 초기화되어 복잡한 신념 체계를 만들지 못함

표 3은 15개 지표를 각각 검정했고 5개가 유의했습니다. 다중 비교 보정은 본문에 언급이 없습니다.

각 틀에서 n=40이고 한 뉴스당 시뮬레이션 횟수는 서술되지 않았습니다.
